# Glossary

- **Asset**: a wardrobe item treated as a durable object with history and actions.
- **Asset Manifest**: the curated list of assets used as constraints/anchors for recommendations.
- **Capsule**: an outfit or set of items recommended to work together for a situation.
- **Context**: user-provided signals (images/video/links) about environment, role, and style.
- **Curation Queue**: the rolling list of generated product candidates in the feed.
- **Deduction Chain**: the step-by-step reasoning sequence that supports an insight or recommendation.
- **Digital Wardrobe Twin**: the system’s structured representation of what a user owns.
- **Evidence Locker**: the UI area that shows linked artifacts supporting a reasoning step.
- **Flow UX**: an interface style designed to minimize context switching and decision fatigue.
- **Insight**: a structured claim produced from context analysis (with confidence).
- **Shortlist**: a decision workspace for items under consideration.
- **Style Matrix**: the calibration phase where a user selects items to define taste.
- **Vectorization**: converting messy inputs into structured parameters (“vectors”).
