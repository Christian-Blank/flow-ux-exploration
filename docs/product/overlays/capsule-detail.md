# Capsule Detail

## Purpose

- Present an outfit/capsule as a coherent, situation-based recommendation.
- Explain *why* the capsule works and what parts are already owned.

## Trigger(s)

- From inventory item detail: `VIEW FULL CAPSULE`
- From shortlist drawer: capsule selection (when implemented)

## Dismissal

- Back button returns to the previous view (inventory item detail / drawer).

## Layout

1. Header:
   - Capsule name
   - Match score badge
   - Situation label
   - Share action (placeholder)
2. Visual composition:
   - Collage-like arrangement of capsule items.
3. AI stylist notes:
   - Capsule reasoning + context framing.
4. Item breakdown:
   - List of items with ownership labeling (“OWNED” vs “SHOP”).
5. Actions:
   - Plan outfit (placeholder)
   - Save capsule (implied persistence)

## Intended Enhancements (Beyond Mock)

- Allow swapping items in the capsule while maintaining constraints.
- Allow scheduling capsule wears and tracking outcomes.
- Allow sharing as a compact story (collage + notes + items).
