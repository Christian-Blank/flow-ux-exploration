# Expanded Image Modal

## Purpose

- Let users inspect product imagery in full-screen detail.
- Support “zoom-in” behavior without leaving the feed.

## Trigger(s)

- In product feed: click the main image.

## Dismissal

- Click anywhere on the backdrop (modal is click-to-close).

## Layout / Behavior

- Full-screen dark backdrop.
- Centered image, contained to viewport.
- Cursor indicates zoom-out behavior.

## Notes

- In a production spec, consider adding:
  - swipe navigation on mobile,
  - keyboard navigation,
  - image index/metadata.
